# 常亮 · 屏幕常亮

一个纯 Kotlin / 无第三方依赖的 Android 小工具。通过一个 **1×1 透明悬浮窗** 让屏幕保持点亮，切换到任何应用都有效；支持定时自动结束，适合系统息屏上限只有 10 分钟、但需要长时间亮屏的场景。

- 版本：**1.1.4**（versionCode 8）· 黑红赛车仪表盘 + 自定义挡
- 安装包：[下载 1.1.4 APK](https://github.com/Maple2085/ChangLiangApp/releases/download/v1.1.4/ChangLiang.apk)（[查看全部 Releases](https://github.com/Maple2085/ChangLiangApp/releases)）
- 安装环境：Android 8.0+（minSdk 26）
- 用户界面：黑红转速表、挡位条、点火键、赛前检查灯；首次打开播放入场动画

## 使用

1. 安装 APK，打开「常亮」。
2. 首次使用点「开启悬浮窗权限」，在系统设置里允许「显示在其他应用上层」。
   - 如果开关是灰的 / 提示「受限设置」，先到「应用信息 → 右上角 ⋮ → 允许受限设置」，再回来开启。
   - vivo / OriginOS 如果找不到入口，可在 i 管家 → 应用管理 → 权限管理 → 悬浮窗里授权。
3. 选择时长：5 / 10 / 15 / 20 / 30 分钟、1 小时、2 小时、始终常亮。
4. 点「开始常亮」。可以切到任意应用。
5. 通知栏会显示剩余时间，点「结束常亮」随时停止；到点也会自动停止。

> Android 13+ 第一次开始时会询问通知权限。拒绝也能继续常亮，但通知栏里看不到倒计时和结束按钮，建议允许。

## 入场动画

通电扫描线 → 五盏发车灯逐个点亮（每盏一下震动）→ 熄灯起步 → 转速表扫到红线 → 回落到当前挡位 → 表盘和「常亮 / KEEP AWAKE」缩放飞入主界面的真实位置。约 3.4 秒，点屏幕或按返回键直接跳到收尾。

- 只播一次。想再看：设置 → 入场动画，打开后**下一次启动**重播一次，播完开关自动关闭。
- 系统关闭了动画（开发者选项里动画缩放为 0）时不播，也不记为已播。
- 衔接原理：入场层和主界面的表盘都调用 `GaugeRenderer` 并读同一份 `GaugeState`，品牌字复用标题 TextView 的画笔；最后一帧两者逐像素重合，同一帧里显出真实控件并移除入场层。

## 操作

- 挡位条可点也可拖：5 / 10 / 15 / 20 / 30 分钟、1H、2H、∞、**SET（自定义）**
- ∞ 档和超过 2 小时的自定义挡要**按住**点火键约 0.8 秒，防止误触后长时间亮屏；按住期间震动越来越密、越来越重，按满一记重震点火（需要 VIBRATE 普通权限，安装即授予）

### 自定义挡（SET）

- 第一次点 SET：打开调表板（PIT BOARD）
- 之后点 SET：直接选中上次设的值；已选中时再点一下或**长按**，重新打开调表板
- 调表板：左右拖动刻度尺（可甩动、松手吸附）；−/+ 微调；45M / 90M / 3H / 6H 快捷值
- 刻度步长：30 分钟内每 1 分钟，30 分钟–2 小时每 5 分钟，2–12 小时每 10 分钟；范围 1 分钟–12 小时
- 调表时主界面表盘实时预览；点「确认挡位」才生效，关闭或返回键不改原值
- 超过 2 小时：指针落在 2H 与 ∞ 之间的红线区，SET 格数字转红
- 自定义值单独记住（`custom_minutes`），切到预设挡再切回来不会丢
- 表盘底部 P N D ∞：P 缺权限，N 待机，D 计时中，∞ 无限
- 最后 60 秒数字转红并脉冲

## 原理

```
用户点开始
  └─ 前台服务 KeepOnService
       ├─ 在屏幕角落添加 1×1 透明悬浮窗（TYPE_APPLICATION_OVERLAY）
       ├─ 窗口 flags 带 FLAG_KEEP_SCREEN_ON
       └─ 通知栏显示倒计时 / 结束按钮
```

- 悬浮窗只有 1 个像素、完全透明、`FLAG_NOT_TOUCHABLE`，不遮挡内容也不拦截触摸。
- 只负责「保持点亮」，不修改系统休眠时间，不申请 WAKE_LOCK。
- 停止或到点后移除悬浮窗，屏幕马上回到系统原本的休眠策略。
- 前台服务让进程在切换应用后继续存活；从最近任务划掉应用也不会停止常亮。
- 到点熄火有三重保险：醒着时每 10 秒按真实时间巡检；亮屏 / 解锁 / 改时间时立即检查；到点由系统闹钟唤醒检查。单靠 `Handler.postDelayed` 会在 CPU 休眠时停摆，导致过点不熄火。
- 应用被系统杀掉后会用 `START_STICKY` 尝试恢复；定时结束时间会持久化。

## 文件结构

| 路径 | 作用 |
|---|---|
| `MainActivity.kt` | 主界面、挡位、点火、权限、设置面板、入场调度 |
| `KeepOnService.kt` | 前台服务、透明悬浮窗、通知、自动熄火 |
| `GaugeRenderer.kt` | 转速表绘制 + 色板；主界面与入场共用 |
| `GaugeView.kt` | 表盘控件：指针动画、红线抖动、最后一分钟脉冲 |
| `IntroView.kt` | 入场动画与无缝变形 |
| `Controls.kt` | 挡位条（9 格）、点火键、开关、碳纤维背景 |
| `RulerView.kt` | 调表板的刻度尺 |
| `CrashLog.kt` | 崩溃写入 下载/DSH-Go/ChangLiang-crash.txt |
| `res/layout/activity_main.xml` | 布局与设置面板 |
| `tools/make-icon.py` | 生成图标预览（启动图标本身是矢量） |
| `build-apk.sh` | 纯手机手工构建脚本 |

## 构建

工具链在 `~/buildtest`（aapt / zipalign / apksigner / JDK 21 / kotlinc / d8）。容器清理后 jar 会丢，先跑 `bash tools/setup-toolchain.sh` 重建：

```bash
cd /sdcard/Code/ChangLiangApp
bash build-apk.sh          # 调试构建，版本不变
bash build-apk.sh --bump   # 交付构建，versionName +0.0.1、versionCode +1
```

构建完成后：

- 项目根目录：`ChangLiang.apk`
- 自动复制到：`/sdcard/Download/DSH-Go/ChangLiang.apk`

> 本项目使用 `targetSdk 33`：手机上的 aapt v0.2 只能稳定读取 platform-28 的资源表，target 34+ 需要声明前台服务类型，会引入平台资源兼容问题。Android 14+ 对 target 33 的应用不强制前台服务类型；核心悬浮窗与通知功能一致。

## 注意事项

- 部分国产系统的省电策略仍可能杀掉后台；如果常亮会意外中断，请在系统设置里允许「常亮」自启动 / 后台运行。
- 这是侧载 APK，Android 13+ 可能把「悬浮窗」归入受限设置；按上面的「允许受限设置」操作即可。
- 上滑清理最近任务不会停止常亮；想停止请用应用内按钮或通知栏按钮。
- 手动按电源键熄屏不受影响；本应用不阻止电源键。
- 本应用不修改系统设置里的「休眠时间」。
